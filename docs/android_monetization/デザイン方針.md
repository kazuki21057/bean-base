# 公開版(Android)デザイン方針とトークン体系

対象タスク: T5-B20(設計)。本書は T5-B21〜T5-B28 の実装が**設計判断をせずに進められる**ことを目的とする。
関連: [コードベース構成方針.md](./コードベース構成方針.md)(差分の置き場所ルール §3 が上位規約)、[収益化アイデア.md](./収益化アイデア.md) §9-2(オンボーディングの根拠)、`docs/改修マスタープラン.md` §3 トラックB/P2。

**適用範囲**: 公開版(`lib/main_public.dart` 起点、`kPublicEdition`)のUIのみ。personal版(`lib/main.dart`)の見た目は本書の対象外で、**1行も変更しない**。

## 1. デザインの方向

### 1.1 コンセプト —「計器(Instrument)」

このアプリの中身は**数値と時間**である(豆量g・湯量g・湯温℃・秒・比率・1〜10の評価)。したがって公開版は「コーヒーの雰囲気を再現した紙のノート」ではなく、**キッチンに置く計器**として設計する。

- 面(サーフェス)は**冷たいスレート**。既定の"コーヒーアプリ"配色(クリーム地+セリフ+テラコッタ)を意図的に採らない。personal版の黒板/コーヒートーンとも視覚的に別物にする。
- **暖色(アンバー)は「いま抽出している」ことだけに使う**。抽出していない間、画面に暖色は一切出ない。これが本アプリの唯一の色彩ルールであり、タイマー起動の瞬間に画面が温まる体験そのものが差別化になる。
- 文字の個性は**数字**が担う。数値・単位・秒はすべて等幅(tabular)で組み、桁が動いてもレイアウトが揺れない。

### 1.2 署名要素 —「抽出リング」(`BbExtractionRing`)

1つの円形部品が、抽出の全ライフサイクルを通じて同じ形で登場する。これがアプリの記憶される要素であり、大胆さはここだけに使う(他は徹底して静かに保つ)。

| 場面 | 見え方 |
|---|---|
| 抽出中(P210) | 直径 240dp。円周=計画総時間。塗られた弧=経過時間(`live`アンバー)。外周の目盛=注湯ステップの境界。中央に現在の目標湯量を `numeralXl` で表示 |
| ホーム(P100) | 直径 96dp。最後の抽出のリングを静止表示(アンバーではなく `primary`)+「もう一度淹れる」 |
| 履歴の行(P240) | 直径 36dp。**抽出の指紋**としてリスト左端に並ぶ。ステップ数と時間配分の違いが形の違いとして見える |
| インサイト(P300) | 2つのリングを重ねて前回との差を示す |

リングは常に**同一の描画ロジック**(`BbExtractionRing(steps, totalSeconds, elapsedSeconds, diameter, mode)`)で、サイズとモード(`live` / `static` / `thumbnail`)だけが変わる。

### 1.3 タイポグラフィの方針(和文の制約を含む)

- **和文・UI文字: プラットフォーム既定フォント**(Android は Noto Sans CJK JP)。理由は APK サイズ。日本語フォントを同梱すると1ウェイトあたり 3〜4MB 増え、既に 63.6MB ある APK に対して割に合わない。字形の日本語解決は既存の `flutter_localizations` + `supportedLocales: ja`(T3-28の対処)で担保済み。
- **数字・単位・ラテン: IBM Plex Mono(Latin subsetを同梱)**。Regular(400)/SemiBold(600) の2ウェイトのみ、`assets/fonts/` に配置し `pubspec.yaml` の `fonts:` で `IBMPlexMono` として登録する。目安 200KB 未満。ライセンスは SIL OFL 1.1 で同梱可、`assets/fonts/OFL.txt` を同梱し設定画面のライセンス表示(`showLicensePage`)に登録する。
- **`google_fonts` の実行時ダウンロードは公開版で禁止**する(`lib/main_public.dart` の起動時に `GoogleFonts.config.allowRuntimeFetching = false;`)。公開版の無料ユーザーはサーバに一切アクセスしない設計(マスタープラン §3 トラックB/P4 の前提)であり、初回起動がオフラインでもフォントが化けてはならない。personal版(`lib/main.dart` の `GoogleFonts.outfitTextTheme()`)はこの設定の影響を受けない位置に置くこと。

サイズは論理値で持ち、`MediaQuery.textScaler` を殺さない。`textScaler` 2.0 でカードと行が破綻しないこと(高さ固定ではなく最小高 `minHeight` で組む)。T5-B28の検証項目に入れる。

|---|---|---|---|

| `floating` | 3 | 影 y=2 blur=6、`shadow` 10% | 影なし。`surfaceContainer` |

**規則**: ダークモードでは影を使わない(黒地に黒い影は見えず、ぼやけるだけ)。段差はサーフェスのトーンで表す。`surfaceTintColor` は `Colors.transparent` に固定し、M3 の自動ティントで色が濁るのを防ぐ。

### 5.4 `BbMotion`

`fast = 120ms` / `base = 200ms` / `slow = 320ms` / `ring = 400ms`(リングの弧のアニメ)。カーブは `standard = Curves.easeOutCubic`、`exit = Curves.easeInCubic` の2つだけ。

`MediaQuery.disableAnimationsOf(context)` が true のときは全時間を 0 にする(リングは弧の位置だけ即時更新)。タイマーの秒読みは「アニメーション」ではないので常に動く。

## 6. ダークモードの方針

**現状の事実**: 既存アプリにダークモードは実装されていない。`lib/main.dart` は `theme:` のみで `darkTheme`/`themeMode` を持たず(`ThemeData(colorScheme: ColorScheme.fromSeed(seedColor: mainColor), useMaterial3: true, textTheme: GoogleFonts.outfitTextTheme())`)、`lib/` に `darkTheme`/`ThemeMode`/`Brightness.dark` の参照は1件も無い(`test/golden/golden_test_helper.dart` がテスト側で `Brightness.dark` を自前指定しているのみ)。

**公開版での入れ方**:

1. `buildPublicTheme(Brightness brightness) → ThemeData` を1関数で提供し、`lib/main_public.dart` で `theme: buildPublicTheme(Brightness.light)`、`darkTheme: buildPublicTheme(Brightness.dark)`、`themeMode: ref.watch(publicThemeModeProvider)` を渡す。
2. `publicThemeModeProvider` の初期値は `ThemeMode.light`(D6)。起動時に `shared_preferences` の `public_theme_mode` を読んで反映する。設定画面(P900)に3択のセグメント「ライト / ダーク / 端末に合わせる」を置く。
3. **ダークを先に設計し、ライトを後から検算する**。本アプリはキッチンでの早朝・夜間利用が主で、タイマー画面を暗所で見る時間が長い。
4. personal版(`lib/main.dart`)には `darkTheme` を追加しない。

## 11. 無料/Proの視覚的表現

- **バナー広告(無料のみ)**: 一覧系(P240 / P5x0)の**最下部のみ**。`adSlotBackground` の固定高 `adSlotHeight`(64)の枠を読み込み前から確保し、レイアウトが飛ばないようにする。上に `outlineVariant` 1px。P210(抽出中)・P220(評価)・P400〜P430(オンボーディング)には**出さない**。インタースティシャルは使わない。
- **Proバッジ**: `tertiary` 系。`BbBadge`(角丸 `xs`、`labelSmall`、テキスト「Pro」)。**機能をグレーアウトして見せない**——使えない機能は淡色で残すのではなく、Pro導線カードとして置き換える。

## 12. アクセシビリティと品質の下限

1. コントラスト: 本文 4.5:1 / 大きい文字・アイコン・グラフ要素 3:1。
2. タップ領域 48×48dp 以上(T5-B28)。
3. 色だけで意味を伝えない(D8)。
4. `textScaler` 2.0 で内容が読める(切り捨て・重なりなし)。
5. すべての図形要素(リング・チャート・バッジ)に `Semantics` ラベル。
6. アニメーション低減設定を尊重(§5.4)。
7. 画面の主要動線はキーボード/フォーカス移動でも到達できる(Web版も同じコードを共有するため)。
